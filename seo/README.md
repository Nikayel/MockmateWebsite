# SEO: manual steps

Everything in this folder is work a human has to do **outside the codebase**: platform settings,
Search Console, and content decisions. None of it can be done by a commit, and none of it is covered
by CI, which is exactly why it is written down.

Context: the Learn corpus used to be 100% behind a login redirect while `sitemap.xml` advertised it.
Several hundred lesson pages are now public, statically generated, and indexable. That change is
live in the code. These tickets are what makes it actually earn traffic.

## Order

Do Phase 1 **before** the deploy that publishes the corpus. Two of those tickets are one way doors:
you cannot recover a "before" baseline after the fact, and link signals lost to a temporary redirect
do not come back on their own.

## Numbers move daily

A concurrent authoring loop ships lessons continuously. Between two consecutive days of writing these
tickets the corpus went from 368 lessons / 23 levels / 471 sitemap URLs to 425 / 28 / 537. So no
ticket hardcodes a count. Where a number matters, run this:

```bash
npx tsx -e "
import sitemap from './app/sitemap'
import { listAllCatalogEntries, listAllCourseLevels, COURSE_IDS } from './lib/tutorials/course-catalog'
const u = sitemap().map(e => e.url)
const lessons = listAllCatalogEntries()
console.log('sitemap URLs:', u.length)
console.log('lessons:', lessons.length, '| levels:', listAllCourseLevels().length, '| tracks:', COURSE_IDS.length)
console.log('titles over 60 chars:', lessons.filter(e => e.lesson.title.length > 60).length)
console.log('summaries over 160 chars:', lessons.filter(e => e.lesson.summary.length > 160).length)
"
```

Figures quoted in tickets are marked with the date they were taken.

## What is already handled in code, so you do not need to

Listed so nobody redoes it:

- The sitemap derives every Learn URL from the curriculum registries at build time, so it tracked a
  whole course rename (`/learn/sql` to `/learn/data-engineering`) with zero edits.
- `robots.txt` is generated by `app/robots.ts` and shares one origin constant with the sitemap and
  every canonical tag. The old static `public/robots.txt` was deleted; do not re-add it, since a
  static file shadows the route.
- Lesson workspaces (`/workspace`) are noindexed and never appear in the sitemap. They are
  deliberately **not** disallowed in robots.txt, because a disallowed URL is never fetched and
  therefore never reveals its noindex.
- Structured data: `Course list` on the Learn hub, `Course` plus `ItemList` on each track, `ItemList`
  plus breadcrumbs on levels, breadcrumbs on lessons. Practice problem, Quiz, and LearningResource
  were deliberately skipped (retired or never eligible).
- A corpus wide test asserts no reference solution, hidden test, or model answer can reach a public
  page.
